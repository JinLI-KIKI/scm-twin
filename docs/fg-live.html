How to read it. Values on the left are the model's current inputs; an orange value differs from the base case in data/fg_params.csv. In range mode each run draws every input with a range from a triangular distribution between its low and high, peaking at the slider value, so the P10–P90 bands widen with what is not known. Inputs that change the calendar (build-to-MGI weeks, tail weeks, MGI cover) stay fixed in range mode.

Engine. src/dash/fg_engine.js is a line-by-line port of src/finished_goods.py with the same random numbers; tests/test_fg_parity.py checks they agree for every strategy. Rules behind each step are in the Rules register; the formulas are written out in docs/models/finished_goods.md.
